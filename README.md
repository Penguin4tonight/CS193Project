# Project MVP

An application that can add and retrieve crop data to a csv and based on that data, display the remaining crop lifespan and the current stage its in.

## The Problem

As a person who likes to plant tomatoes back at home, I want to build an application to track the lifecycle of my crops. When it comes to gardening the most important thing is staying on top of crop lifecycles and understanding when to harvest the fruits of the crops and how much time it has left. 

## How It Works

To solve the issue of managing the lifecycle and harvest dates of crops I plan on building a react application that stores the current lifecycles of a person's crops. From that storage the app can then use the current date to decide when crops need to be harvested and what stage in the lifecycle they are in. 

## Tech Stack

- **Language:** React, JavaScript, CSS, HTML, JSON(if not using CSV).
- **Libraries:** PapaParse or React-CSV-Reader
